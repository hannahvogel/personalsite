# Template provenance

This website began from `vsimkus/academic-jekyll` at commit
`a31e58fcd1082ea34107677585647731fd2a24e3`, copied without fork history on
20 August 2026. Academic Jekyll is MIT-licensed and derives from Jekyll Now.

This version replaces the demo identity, prose, images, sample publications,
Bootstrap and jQuery interaction code. It adds semantic landmarks, local styles,
keyboard focus treatment, content provenance, dual licensing, automated builds,
and accessibility and Lighthouse checks. The template code remains under the
MIT licence in `LICENSE`.
